# Сервер заказов витрины (Google Apps Script)

`Code.gs` — шаблон без секретов. Перед установкой заполните в начале файла `BOT_TOKEN`, `ADMIN_KEY`, `HOOK_KEY`.
Никогда не коммитьте файл с настоящим токеном: репозиторий публичный.

Схема: сайт (GitHub Pages) → `doGet ?a=init` (каталог, зоны, занятые интервалы) и `doPost {a:'order'}` (заказ)
→ Google-таблица (Каталог / Заказы / Клиенты / Настройки) → Telegram-бот (вебхук на тот же `/exec?k=HOOK_KEY`).

Установка: создать таблицу → Расширения → Apps Script → вставить код → `setup()` → Развернуть как веб-приложение
(от имени: я, доступ: все) → URL в «Настройки» → `connectBot()` → открыть ссылку владельца из журнала.
Адрес веб-приложения вписать в `index.html` в константу `API`.
